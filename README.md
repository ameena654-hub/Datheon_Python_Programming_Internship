# Datheon_Python_Programming_Internship
This repository contains Python projects developed as part of the Datheon Python Programming Internship.

## Projects

### 1. Hangman Game
A terminal-based word guessing game.
- Random word selection
- Maximum of six incorrect guesses
- Tracks guessed letters
- Prevents duplicate guesses

**File:** `hangman.py`

### 2. Investment Portfolio Tracker
A Python application that calculates investment values and profit or loss.
- Records stock ticker symbols
- Calculates invested and current values
- Calculates gain or loss percentage
- Stores investment details in CSV format

**File:** `portfolio.py`

### 3. File Organizer
A program that organizes files into folders based on their extensions.
- Uses `os.scandir()` to scan files
- Uses `shutil.move()` to move files
- Creates category folders automatically
- Handles duplicate filenames and permission errors

**File:** `organizer.py`

### 4. FAQ Chatbot
A rule-based chatbot that answers frequently asked questions.
- Uses regular expressions for keyword matching
- Answers predefined FAQs
- Remembers the user's name during the conversation
- Provides fallback responses
- Stores FAQ information using JSON

**Files:** `chatbot.py`, `chatbot_data.json`

## Technologies Used
- Python
- CSV
- JSON
- Regular Expressions
- os module
- shutil module

## How to Run

Make sure Python is installed on your computer.

Open the terminal in the project directory and run:

```bash
python hangman.py
```

```bash
python portfolio.py
```

```bash
python organizer.py
```

```bash
python chatbot.py
```
